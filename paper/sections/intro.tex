Mechanistic accounts often credit one cache channel: keys act as routers \citep{ma2025addressbook}, Llama models carry binding information mainly in key vectors \citep{oh2026rebinding}, and refusal steering acts mainly through the OV circuit \citep{cheng2026steering}. Later tokens see a token only through its cached key and value, so a written value can reach the answer in two ways (\cref{fig:schematic}a): it is \emph{looked up} when a later token that already holds a candidate matches the writing token's key, so that the key carries which value was written, and \emph{copied} when the identity travels in the value. We show that where the candidates are mentioned, relative to the token that writes the value, can decide the route. Whether the accounts above depend on this we did not test (\cref{sec:limitations}, ix).

In the belief stories of \citet{anonymous2026fitted}, one token, which they call the critical token and we call the \emph{writing token}, states where an object was moved. We clamp its cached key and value separately and vary whether and where the candidates are named again: in \nModels{} discovery-sample models from three families; in a preregistered confirmation on 150 newly drawn stories in eight models from seven families, four never examined before; and on counterfactual reading-comprehension passages. Each of the final round's \JxLinesABCD{} predictions was preregistered with a probability of holding and, if primary, the text to print for each outcome; we name every failure. From \citet{anonymous2026fitted} we take only the story template and, in \cref{sec:claim3}, one released remap (a learned subspace edit) and its training code.

\paragraph{What is known, and what we add.}
Known circuits attend to earlier copies, select listed options by query--key alignment and retrieve bound entities (\cref{tab:qkov}; \citealp{tulchinskii2024wise,feng2023binding,dai2024binding,prakash2024finetuning,prakash2025lookbacks,gurarieh2025mixing}); in a known write-then-select structure, shallower heads write a routing feature into option rows that decision heads attend to \citep{sun2026persuaded}. Without a later mention no later token holds a candidate, so copying is close to forced; with one, both routes are open. We claim no new head type and add three results.
(1)~Where the candidates are mentioned decides the route in every family we tested, and in generated answers: with a later list a value-only clamp changes few of them, and the copy route remains as a fallback (discovery sample; passages\rsk; \cref{sec:claim1,sec:claim2}).
(2)~In two 7B models, the heads that make the match, enriched for duplicate-token heads (discovery sample), write at the written word's later mention a component that is the same whichever value was written; it suffices to move the answer, which selects the flagged row by key (a K-composition; \citealp{elhage2021framework}), but it is neither specific nor the only carrier. In lists (discovery sample), the written value is thus read at its later mention, not looked back for at the token that states it. The question sets the read's sign after the reader heads (exploratory), and IOI's opposite-signed key and value reads are consistent with S-inhibition \citep{wang2022ioi} (\cref{sec:claim2}).
(3)~A preregistered law predicting an edit's apparent channel from the model's own channel ratio failed (\cref{sec:claim3}): an intervention's channels must be measured.

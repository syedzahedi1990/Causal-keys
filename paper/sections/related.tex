\section{Related Work}\label{sec:related}

\paragraph{Options, belief stories and heads.}
Specific heads select among listed options \citep{lieberum2023chinchilla,wiegreffe2025answer}, some by query--key alignment \citep{tulchinskii2024wise}, as our second hop selects the flagged option rows by key. Closest to our first hop, shallower heads write into option rows a one-dimensional routing feature that redirects decision heads' attention \citep{sun2026persuaded}; our flag plays this role, written by a match to the token that wrote the value and the same whichever value was written. On belief stories, belief and reality share a value slot read out under a router at the query \citep{steele2026routing}, and lookbacks built on ordering IDs retrieve the state token to track beliefs \citep{prakash2025lookbacks}; in our terms both are compatible with a copy route, in which the identity travels in the value of the token that states it, and later mentions add a second route, a lookup addressed at the mention.

\paragraph{Attributing interventions.}
Interchange interventions \citep{geiger2021inducing,geiger2024finding} may act through pathways the model does not use naturally (\citealp{makelov2024subspace}, contested by \citealp{wu2024reply}; \citealp{liu2026wrong}); steering vectors \citep{turner2023actadd,panickssery2023caa} need not reproduce natural activations \citep{shih2026steering} and are brittle to prompt changes \citep{tan2024steering}. Prompt format changes what is measured \citep{sclar2023quantifying,opielka2026causality}, as does the answer encoding of a steering gain \citep{gao2026encodings}; we find the same for an edit's apparent cache channel. Cache-level accounts place routing or binding information in keys \citep{ma2025addressbook,oh2026rebinding} or find an operation's cache read mainly as an address \citep{wu2026record}; in our stories the token that wrote a value is read mainly through its key only when a later token re-mentions the candidates.

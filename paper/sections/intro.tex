Mechanistic accounts often credit one cache channel: keys act as routers \citep{ma2025addressbook}, Llama models carry binding information mainly in key vectors \citep{oh2026rebinding}, and refusal steering acts mainly through the OV circuit \citep{cheng2026steering}. Later tokens see a token only through its cached key and value, so a written value can reach the answer in two ways (\cref{fig:schematic}a): it is \emph{looked up} when a later token that already holds a candidate matches the writing token's key, so that the key carries which value was written, and \emph{copied} when the identity travels in the value. What decides which route a model takes, and what follows for interventions credited to one channel?

In the belief stories of \citet{anonymous2026fitted}, one token, which they call the critical token and we call the \emph{writing token}, states where an object was moved. We clamp its cached key and value separately and vary whether and where the candidates are named again: in \nModels{} discovery-sample models from three families; in a preregistered confirmation on 150 newly drawn stories in eight models from seven families, four never examined before; and on counterfactual reading-comprehension passages. Before the final round we recorded a probability of holding for each of its \JxLinesABCD{} predictions and, for each primary one, the text to print for each outcome; we name every failure. From \citet{anonymous2026fitted} we take only the story template and, in \cref{sec:claim3}, one released remap and its training code.

\textbf{Findings.} Later mentions decide the route (\cref{sec:claim1}): a key-only clamp changes \pctn{\JbRangeBetaKAfterEightMin}--\pct{\JbRangeBetaKAfterEightMax} of generated answers in all eight confirmation models when the candidates are listed after the story, a value-only clamp most of them without a later mention (\cref{fig:schematic}b,c); on passages a later options list opens the key read. In two 7B models the lookup is a duplicate-token match writing a flag that the answer reads by key, sufficient but neither specific nor the only carrier (\cref{sec:claim2}). A preregistered law predicting an edit's apparent channel from the model's own channel ratio failed (\cref{sec:claim3}).

\paragraph{What is new.}
Every attention head factors into a QK circuit, which decides where it attends, and an OV circuit, which decides what it moves \citep{elhage2021framework}; known circuits attend to earlier copies, select among options and retrieve bound entities (\cref{tab:qkov}; \citealp{tulchinskii2024wise,sun2026persuaded,feng2023binding,dai2024binding,prakash2024finetuning,prakash2025lookbacks,gurarieh2025mixing}). None of this says which route a model takes, because the copy route is always open. We claim no new head type. We add, each by a preregistered test, that where the candidates are mentioned decides which route carries the identity, in every family we tested and in generated answers; and that the duplicate-token match writes into the mention's row a component that is the same whichever value was written and suffices to move the answer (though structured controls move it too), which the answer selects by key: the duplicate signal is consumed through keys, and which value was written is read at the later mention, not looked back for at the token that states it. The same reader heads carry the read whether the question asks for a mentioned or an unmentioned option, the sign being applied after them (exploratory); a key read of opposite sign to the value read, as with IOI's re-mentions, is consistent with S-inhibition \citep{wang2022ioi}.

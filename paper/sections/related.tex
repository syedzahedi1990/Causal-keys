\section{Related Work}\label{sec:related}

\paragraph{Options, binding and retrieval.}
Heads select among options \citep{lieberum2023chinchilla,wiegreffe2025answer,tulchinskii2024wise,sun2026persuaded}, choosing a winner before binding it to a symbol \citep{wong2026decide}. Binding IDs \citep{feng2023binding}, key-side rebinding \citep{oh2026rebinding}, value-slot routers \citep{steele2026routing,steele2026spaces} and cached-KV edits \citep{bojieli2026notes} concern storage.

\paragraph{Closest work.}
\citet{prakash2025lookbacks} describe their state-token patch as swapping addresses, read through QK, and payloads, moved through OV; split between keys and values it is key-dominant, with a substantial value share without a later mention (\cref{sec:prakash}). This fits both halves of their account without separating them, and corrects our earlier reading of lookbacks as a copy read (\cref{app:discussion}). \citet{wu2026record} find an operation's cache read mainly as an address, moving keys and values together in one format; \citet{ma2025addressbook} find keys to be sparse routers and values dense payloads. With the channels separated and the format varied, whether keys route identity depends on the prompt: it is a payload without a later mention and a key read with one (at hop~2 by an unscored contrast). \citet{zhou2026ordinal} finds that questions address facts by order of mention; compatibly, though not as a test, the binding swap, an order-of-mention edit at the stored state token, is read mainly through keys. Our readers' core is duplicate-token heads, not the token- or concept-level induction heads of \citet{feucht2025dualroute}; the read is form-bound on our English measure yet concept-like for French-mixed re-mentions at two Qwen models (exploratory; \cref{app:g-forms}), which leaves token versus concept open. Options before the context cannot attend to it \citep{ok2026lost}; with the same words, moving the list before the writing token closes the key read (E1). Steering is brittle to prompt changes \citep{tan2024steering}; here behaviour stays stable while the channel flips.

\paragraph{Validity, format dependence and patching.}
Interchange interventions \citep{geiger2021inducing,geiger2024finding} may act through dormant or planted pathways \citep{makelov2024subspace,wu2024reply,liu2026wrong}, need not reproduce natural activations \citep{shih2026steering} and are not identifiable from behaviour \citep{venkatesh2026steering}; diagnostics include control tasks \citep{hewitt2019control}, benchmarks \citep{huang2024ravel,arora2024causalgym,mueller2025mib} and input partitions \citep{li2026bucketing}. Format changes alter performance, function vectors and what a steering gain identifies \citep{sclar2023quantifying,opielka2026causality,gao2026encodings}; refusal steering acts mainly through OV \citep{cheng2026steering}, introspection through injected key and value changes \citep{zou2026introspection}. Patching \citep{vig2020causal,wang2022ioi} depends on metric and corruption \citep{zhang2023patching,heimersheim2024patching}; precomputed KV caches substitute exactly for a joint pass \citep{pustovit2026packs}, as our joint clamp does.

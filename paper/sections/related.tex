\section{Related Work}\label{sec:related}

\paragraph{Multiple-choice mechanisms.}
Attention heads select among listed options: ``correct letter'' heads whose query and key subspaces partly encode an enumeration index \citep{lieberum2023chinchilla}, middle-layer attention behind the answer symbol \citep{wiegreffe2025answer}, select-and-copy heads found by pre-RoPE query--key scores \citep{tulchinskii2024wise}, decision heads that copy the attended option \citep{sun2026persuaded}, and a winner chosen in content space before it is bound to a symbol \citep{wong2026decide}. Options placed before the context cannot attend to it \citep{ok2026lost}, which our \fmtBefore{} control exploits. These works ask how an answer is chosen among options; we ask how later mentions read a value written earlier.

\paragraph{Binding, lookbacks and in-context retrieval.}
Models bind entities to attributes with binding ID vectors \citep{feng2023binding}. In belief stories, ordering IDs bound at the state token (our writing token) let lookbacks retrieve the queried state's ordering ID and then the state token itself; these variables are localised in the residual stream, not in the cached key and value \citep{prakash2025lookbacks}. Rebinding signals sit in query/key subspaces or mainly in keys, by model family \citep{oh2026rebinding}; an operation's cache is read mainly as an address rather than a payload \citep{wu2026record}; a router selects which frame is read from a shared value slot \citep{steele2026routing,steele2026spaces}; and editing a field's cached keys and values barely changes a decision later tokens already recorded \citep{bojieli2026notes}. We ask which of the writing token's two channels carries the value's identity, and find that later mentions decide.

\paragraph{Validity of interventions.}
Interchange interventions align causal variables with representations \citep{geiger2021inducing,geiger2024finding}, but may act through dormant pathways \citep{makelov2024subspace,wu2024reply} or planted ones \citep{liu2026wrong}, need not reproduce natural activations \citep{shih2026steering}, and are not identifiable from behaviour \citep{venkatesh2026steering}. Diagnostics include control tasks \citep{hewitt2019control}, benchmarks \citep{huang2024ravel,arora2024causalgym,mueller2025mib} and input partitions \citep{li2026bucketing}.

\paragraph{Format dependence.}
Performance is sensitive to meaning-preserving format changes \citep{sclar2023quantifying}; function vectors from open-ended and multiple-choice formats are nearly orthogonal \citep{opielka2026causality}; and a steering gain under one answer encoding does not identify what the intervention controls \citep{gao2026encodings}. Refusal steering acts mainly through the OV circuit \citep{cheng2026steering}, and introspection depends on how injected key and value changes align with gate heads \citep{zou2026introspection}.

\paragraph{Patching and KV-cache edits.}
Component attribution rests on causal mediation and patching \citep{vig2020causal,wang2022ioi}, whose conclusions depend on metric and corruption \citep{zhang2023patching,heimersheim2024patching}. Precomputed KV caches exactly substitute for a joint pass, and value edits can steer where key arithmetic breaks coherence \citep{pustovit2026packs}; the same causal-mask argument makes our joint clamp exact.
